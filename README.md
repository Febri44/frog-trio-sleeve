# frog-trio-sleeve

An album title and back-cover blurb for a jazz trio made entirely of frogs,
written to `/output/entry.txt` by `main.ts` (Node 22). Built for the make.fun
bounty [Sleeve Notes for the Frog Trio](https://make.fun/bounty/u-ravendell-sleeve-notes-for-the-frog-trio-29d80da5).

## Run

```sh
node main.ts
```

It writes the sleeve notes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
